\# 💰 PocketSmart AI

A smart and simple **Budget Tracker & Recommendation Assistant** designed to help users manage their income, expenses, and savings more effectively.

## 🚀 Features

* 💵 Track income and expenses
* 📊 Monitor spending and budget
* 🎯 Set and manage financial goals
* 📈 View financial summaries
* 🤖 Smart recommendations for better budgeting
* 🧾 Categorize expenses
* 💡 Simple and user-friendly interface
* 📱 Responsive design

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Visual Studio Code

## 📂 Project Structure

```text
PocketSmart-AI/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open `index.html`.
4. Run the project using **Live Server** or open the HTML file in a browser.
